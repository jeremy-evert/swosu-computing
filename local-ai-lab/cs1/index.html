EVIDENCE, NOT GUESSING

Preserve what the machine actually proves

FOUND/MISSING is an inventory result. PASS/FAIL is a readiness result. A legitimate NOT READY result with its first diagnostic is useful evidence, not a student failure.

Ollama, the model, or Aider running does not prove an AI-generated answer is correct. Inspect Git state and the diff, then run an independent test.
