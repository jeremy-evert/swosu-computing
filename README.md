# SWOSU Computing

Public student-facing launchpad for Jeremy Evert's SWOSU computing courses.

This repository is intentionally public. It contains only material explicitly intended for students or the public. Private curriculum planning, prompts, reports, unpublished materials, and answer-sensitive content remain in `jeremy-evert/swosu_cs_curriculum`.

## Public sections

- `/bootstrap/` — Start Here / student setup
- `/office-hours/` — current office hours and where to find Jeremy
- `/cs1/` — Computer Science 1
- `/cs2/` — Computer Science 2
- `/dsct/` — Discrete Structures & Critical Thinking
- `/architecture/` — Computer Architecture
- `/slides/` — deliberately published slide PDFs
- `/examples/` — deliberately published examples and references

Canvas remains authoritative for graded work, due dates, submissions, grades, official announcements, and student-specific information.

## Publication rule

Nothing from private repositories is mirrored automatically. Publication into this repo is explicit and allow-listed.
