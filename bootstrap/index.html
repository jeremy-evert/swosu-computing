PHASE 3

Run the tiny sanity check

You do not need to understand every command yet. We are simply asking the machine to prove that Git is present and that you can see its version.

Terminal / PowerShell
git --version

If you see something beginning with git version, that piece is alive. If the computer says Git is not recognized, return to the Git install step.

Optional identity check
git config --global --list

Do not panic if the second command is sparse. Your course can help you configure name, email, authentication, repositories, SSH, and remotes at the right time.
