FIRST-TIME SETUP

Bring a computer from “new box” to “ready to learn.”

Keep this page open on your phone while you work through the computer.

1. Get your identities working

Do these before worrying about compilers, terminals, or code.

1

SWOSU / Canvas

Confirm you can sign in to your SWOSU account and Canvas. If Canvas works on your phone but not your computer, you still have a path forward.

Open SWOSU Canvas
2

GitHub

Confirm you have a GitHub account you can sign into. Use a personal account you expect to keep after graduation unless your course specifically tells you otherwise.

Open GitHub
3

Email

Confirm you can receive SWOSU email. Course systems and people often use it when something needs your attention.

Email Jeremy if you need help

2. Give the computer a useful toolbox

Install from official sources. Do not download mystery installers from search ads or random mirrors.

Git

Git lets you version, inspect, recover, and share work. It is part of the safety belt.

Official Git downloads

Visual Studio Code

A general-purpose editor that works well with Git, terminals, remote systems, and many languages.

Official VS Code download

GitHub Desktop optional

A graphical Git client. Useful while the command line is still becoming familiar.

Official GitHub Desktop download

Windows Terminal

On Windows, this gives you a clean place to work with PowerShell, Command Prompt, SSH, and later WSL if a course needs it.

Windows Terminal
Course-specific tools come from the course page. C++, Linux/WSL, architecture tooling, VPN/SSH, or other specialized software should only appear when that course actually needs them.

3. Run the tiny sanity check

You do not need to understand every command yet. We are simply asking the machine to prove that Git is present.

Terminal / PowerShell
git --version

If you see something beginning with git version, that piece is alive. If Git is not recognized, return to the Git install step.

Optional identity check
git config --global --list

Do not panic if the second command is sparse. Your course can help configure name, email, authentication, repositories, SSH, and remotes at the right time.
