A durable restart point for a new semester, a new computer, or a day when nothing behaves.

Starting from nil? This page is designed to work from a phone first. Scan the QR code, open this page, and then use it to bootstrap the computer you will use for class.
  1. Confirm you can access Canvas and your SWOSU account.
  2. Set up Git and GitHub.
  3. Set up the editor, terminal, and course tools.
  4. Join the course communication space when the verified Discord invite is published.
  5. Complete the course-specific sanity check.
  6. If stuck, use Office Hours or contact Jeremy.
