# Escape the LLM Dungeon

**A practical field guide to building playable projects with AI assistants, while protecting people, evidence and your professional reputation.**

**Public working draft v0.1 · November 16, 2026.** This is a student-visible roadmap, **not** a completed course, an institutionally approved curriculum, or a claim that participants have mastered these tools.

## What this package is

A teachable map through **18 linked checkpoints**, from safely trying different AI assistants through coding, voice, rules, evidence, testing, and publication. The end product can be **any small interactive website**, not necessarily a spelling game or a quiz.

WordWild, our published educational game, serves as a worked example of the real development process: the strengths of several assistants, the audio pipeline, the value of versioned prompts, a missing sentence feature, and a Check it mouse-button bug missed by Enter-only tests.

## Suggested use

Start with Stage I if you're unfamiliar with assistants and permissions. Experienced students may skip the mock-inbox setup and begin at Stage II (first website). It is fine to use the assistant they already have, to **decline connector authorizations**, or to work from simulated data. No paid subscription is required as a condition of reading this material.

**Six stages:** (I) Plan and connect responsibly, (II) Build and host, (III) Narrate, (IV) Script and respond, (V) Ground against sources, (VI) Test and deploy.

**Working assessment approach:** each checkpoint leaves a tangible artifact; the final release has a live link, tested interactions, source ledger, correct license/attribution, limitations and an explanation of what was human-reviewed.

## Source and status boundaries

- New teacher prose is AI-assisted and human-directed. The first edition is **unreviewed**, so do not treat it as approved institutional guidance.
- Provider features are not stable. Check official documentation before using a connector, service or deprecated model. Example: `gpt-4o-mini-tts` is scheduled for shutdown **January 6, 2027**, so the TTS chapter is about comparing workflows and migrating safely.
- **Only fictional inboxes and harmless sample data are used in the planned exercises.** Real school account access requires applicable university policies and authorization. Never upload student records or private data to arbitrary services.
- The public WordWild demonstration is an example, **not** proof that its jokes improve spelling or that its rules were reviewed by a literacy expert.
- Do not copy private GitHub repositories, full ChatGPT conversations, original student work or credentials into a public release.
- A third-party OER upload (OER Commons, Kolibri, OpenStax, Carpentries, etc.) is **future work**, not part of this first public draft.
